Add layout snapshot-to-workflow to Flow: "save this layout as <name>"
captures the current windows + positions as a replayable recipe. Read
winctl.py, commands.py, workflows.py, agents.py first; match style.

## 1. Capture (winctl.py additions)

- window_process(hwnd): GetWindowThreadProcessId + OpenProcess +
  QueryFullProcessImageNameW -> exe basename (ctypes only, close handles).
- snapshot_layout(): for each visible titled top-level window (reuse
  _windows_list): skip junk (empty/"Program Manager"/"Windows Input
  Experience"/Flow's own overlay+HUD windows), skip minimized. For each:
  GetWindowRect -> nearest monitor (max overlap) -> nearest region: compute
  IoU against each of winctl.REGIONS' rects on that monitor, take the best;
  if best IoU < 0.55 keep exact rect instead: {"do":"place_rect", ...}.
  Return [{exe, title, monitor, region-or-rect}].
- New primitive "place_rect": {"do":"place_rect","arg":<title query>,
  "monitor":N,"x":..,"y":..,"w":..,"h":..} — MoveWindow to exact
  monitor-relative coords (relative so a monitor rearrangement degrades
  gracefully).

## 2. Exe -> openable app mapping (commands.py)

- Map exe basename to a spoken/openable name: first try installed_apps()
  fuzzy match on the exe stem and on the window title's trailing app name
  (" - Google Chrome" suffix pattern); small builtin table for common ones
  (chrome.exe->chrome, msedge.exe->edge, Code.exe->visual studio code,
  WindowsTerminal.exe->terminal, explorer.exe->file explorer). Unmappable
  windows are SKIPPED and reported by name in the spoken summary.

## 3. The skill

- "save this layout as <name>" / "save this setup as <name>" / "remember
  this layout as <name>" (and via intent action). Flow builds a recipe:
  per app (dedupe by exe, keep first window's placement; two windows of
  the same exe -> use title-distinguishing queries when titles differ):
    {"do":"open","arg":<app>}, {"do":"wait_window","arg":<query>,
    "timeout_s":15}, {"do":"place"/"place_rect", ...}
  triggers=[<name>], saved via the existing store. Speak a compact summary:
  "Saved <n> windows: chrome monitor 1 left, code monitor 2 full. Say
  '<name>' any time." If a name collision exists -> Question: replace or
  cancel.
- Scope note in the summary when >0 windows skipped: "Skipped: <titles>".
- Current virtual desktop only (Windows doesn't expose others' windows via
  EnumWindows anyway) — document in the recipe as a comment field.
