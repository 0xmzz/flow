Make Flow's live brain resourceful: machine-state context, proactive wake
greeting, weather skill, Ollama resilience, and an intent-decision corpus.
Read ARCHITECTURE.md, commands.py, live.py, llm.py, winctl.py, workflows.py
first; match style.

## 1. State snapshot -> LLM context (the "aware of the machine" layer)

- New commands.py helper machine_context(): compact plaintext block, built
  fresh per _fallback call, <=400 chars: local time + weekday, open window
  titles (top 8, deduped, truncated), monitor count, saved workflow names,
  whether an agent/workflow is currently running. Cheap calls only
  (_windows_list, winctl.enumerate_monitors, recipe names — no probing).
- Prepend it to BOTH intent extraction and chat calls (alongside the
  existing conversation memory). Guidance line in the prompts: use it to
  ground answers ("which tabs are open") and to prefer workflow/skill
  actions that reference real window names.

## 2. Proactive wake greeting (rules first, LLM for phrasing only)

- When a wake-only "Yes?" interaction OR the first conversation of the day
  starts (track last-conversation date in data/live_state.json), and a rule
  matches, offer instead of a bare "Yes?":
  - morning rule (05:00-11:00, first conversation of the day, a workflow
    whose name/triggers contain "day"/"morning" exists): "Morning. Want me
    to run <name>?" -> yes runs it (reuse the Question mechanism).
  - otherwise fall back to plain "Yes?".
- Keep it ONE rule table (list of (predicate, question, action) entries) so
  more rules are trivial to add; no LLM call on this path (must be instant).

## 3. Weather skill (commands.py)

- "what's the weather (today|now|like)?" / "weather in <place>" -> Open-Meteo
  (free, keyless): geocoding via geocoding-api.open-meteo.com when a place
  is spoken, else cfg["weather_location"] (DEFAULTS: {"weather_location":
  "Dubai"}). Speak temp now, feels-like, condition word, today's high/low.
  Timeout 6s; failure -> "The weather service didn't answer."
- PRIVACY: this is a data-feed egress like CoinGecko — only the location
  string leaves the box. Add it to ARCHITECTURE.md's privacy list.
- Add "price"/"weather" style examples to the intent prompt so phrasing
  variants route.

## 4. Ollama resilience

- llm.py: on connection-refused, retry once after 2s (Ollama restarting);
  flow.py warmup thread: if warmup fails, retry every 60s until it succeeds
  (currently one-shot — an Ollama restart after Flow boot leaves qwen cold
  and the first call times out).
- _fallback: when the LLM is unreachable, answer with a USEFUL static line:
  "My language model is offline — direct commands still work, say help for
  the list." (never the bare "I couldn't reach the assistant").
